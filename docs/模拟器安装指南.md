# MuMu 模拟器 · 安装与 OAID 配置指南

> 本文写给「换一台机器重新搭环境」的场景。装好之后回到 `README.md` 看怎么跑脚本。

---

## 一、模拟器选型

推荐 MuMu，三条理由按重要性排序：

1. **兼容 Hyper-V / VBS**。Windows 11 默认开启「内核隔离 / 内存完整性」（VBS），
   MuMu 官方明确声明已适配 Hyper-V/VBS，系统安全功能保持开启即可正常跑 —— 这是决定性理由。
2. **对 Intel CPU 兼容性最好**。
3. 免费、无广告捆绑、体积小、启动快。

> 备选：Google 官方的 Android Studio 自带模拟器，原生跑在 Hyper-V 上，兼容性最好，
> 但要装整套 Android Studio，偏重。

---

## 二、下载与安装

官方下载地址（**认准官网**）：

- 网易官网：https://mumu.163.com
- 英文站 / 帮助中心：https://www.mumuplayer.com

安装要点：

1. 运行安装包
2. **安装路径改到非系统盘**（模拟器本体 + 虚拟磁盘很能吃空间）
3. 组件按需勾选
4. 等安装完成

记住安装目录，等下要填进 `config.json`。目录结构大致是：

```
<MuMu 安装目录>\
├── nx_main\
│   ├── MuMuManager.exe     ← 命令行管理工具
│   └── adb.exe             ← adb
└── ...
```

## 三、首次启动与配置

### 启动前腾出内存

模拟器约占 4 GB 内存。先把不用的程序关掉（浏览器多余标签页、微信、IDE 等）会更流畅。

### 性能设置

模拟器右上角 **设置 → 高级 → 性能**：

| 项 | 建议值 | 说明 |
|---|---|---|
| CPU 核心 | 4 核 | 取物理核心数的一半以内 |
| 内存 | 4096 MB | 约占物理内存的 1/4；紧张时降到 3072 MB |
| 渲染模式 | 保持默认（或 Vulkan） | 显卡不兼容再切回默认 |

### 显示设置（竖屏）

外星仔是竖屏 app，设成手机比例：

- 分辨率：**1080 × 1920**
- DPI：**320**

（设置 → 显示 → 自定义）

> 脚本后面还会用 `MuMuManager.exe setting -k resolution_mode -val phone.1`
> 把竖屏固定下来，重启后也保持。

### 确认 ADB 调试开启

MuMu **默认就开着 ADB**，装完按第六节验证一下即可。

## 四、装外星仔 + 登录

1. **装 APK**（三选一）：
   - 模拟器内打开自带浏览器，访问官网下载安卓版
   - 或先在电脑上下载 APK 文件，直接拖进模拟器窗口
   - 或模拟器自带应用中心搜索安装
2. **登录**：用手机上**同一个账号**
3. **关键一步**：进 **个人中心 → 设置**，确认 **「看视频免费玩」是开启的**

   > 官方 FAQ 提到：新版可能默认关闭这个开关（尤其买过手游 VIP 的账号）。
   > 打开它，看广告的入口才会出现。

---

## 五、把路径填进 config.json

复制模板并填写：

```bash
cp config.example.json config.json
```

| 字段 | 填什么 |
|---|---|
| `mumu_manager` | `<MuMu 安装目录>\nx_main\MuMuManager.exe` |
| `adb_path` | `<MuMu 安装目录>\nx_main\adb.exe` |
| `mumu_vmindex` | 实例编号，多开器里能看到，通常 `0` |
| `serial` | MuMu 新版 `127.0.0.1:16384`，老版 `127.0.0.1:7555` |
| `oaid` | 任意一个 UUID（第七节要用） |

以上五项都是必填，缺失时脚本直接报错指出缺哪一项。

`config.json` 已被 `.gitignore` 忽略，不会上传。

## 六、验证 ADB 连通

```bash
"<MuMu 安装目录>/nx_main/adb.exe" devices

# 如果上面是空的，手动连一下（端口见第五节）
"<MuMu 安装目录>/nx_main/adb.exe" connect 127.0.0.1:16384

# 再确认
"<MuMu 安装目录>/nx_main/adb.exe" devices
```

看到一行 `127.0.0.1:16384  device` 就算成功。

## 七、必须做的一步：修 OAID

**这一步决定广告能不能加载出来**（`oaid sdk not find` → `无广告填充 1010`）。

广告 SDK 要靠 OAID 才请求得到广告。MuMu 默认伪装成 Xiaomi，没有配套的 OAID 服务，
所以要**改机型品牌 + 注入一个假 OAID**，让广告 SDK 走 OPPO 路径
（OPPO 路径直接读 `persist.oaid` 系统属性）：

```bash
export MSYS_NO_PATHCONV=1
ADB="<MuMu 安装目录>/nx_main/adb.exe"

$ADB root
$ADB wait-for-device          # adb root 会重启 adbd，等它回来再继续
$ADB shell setprop persist.oaid <config.json 里填的那个 UUID>

for k in ro.product.manufacturer ro.product.brand ro.product.vendor.manufacturer \
         ro.product.system.manufacturer ro.product.odm.manufacturer \
         ro.product.vendor.brand ro.product.system.brand ro.product.odm.brand; do
  $ADB shell "/data/adb/ksud resetprop $k OnePlus"
done
```

> 需要模拟器里已装 **KernelSU**（提供 `ksud resetprop`），`ro.*` 属性靠它来改。

**注意**：`ro.*` 是运行时覆盖，**MuMu 每次重启都会还原**，所以每次跑脚本前都要重刷。
`scripts/checkin.py` 里的 `ensure_ready()` 已经自动做这件事，正常情况下不必手动执行：
它先 `adb root` 拿到 uid=0（等 adbd 重启完成、轮询 `id` 确认），再注入属性。

详细原理见 `方案与实施步骤.md` 第四节。

## 八、排查速查

| 情况 | 表现 | 处理 |
|---|---|---|
| 内存吃紧 | 模拟器启动慢、卡顿、app 被杀 | 关掉占内存的程序；性能设置里把内存降到 3072 MB |
| VBS 拖性能 | 模拟器能跑但明显卡 | 设置 → Windows 安全中心 → 设备安全性 → 内核隔离 → 关闭「内存完整性」后重启 |
| 重启后变横屏 | 界面 1920×1080 | `MuMuManager.exe setting -v 0 -k resolution_mode -val phone.1` |
| 广告加载不出来 | `无广告填充 1010` | 见第七节，检查 OAID 与品牌属性是否注入成功 |
